    安全设置

    账单、统计、预算和我的页面需要密码才能查看。初始默认密码为 1234。

    🔐 面容 / 指纹解锁

    在 iPhone 上使用 Face ID 或 Touch ID 快速解锁，无需每次输入密码。需通过 HTTPS 或 localhost 访问，并已在系统中录入面容/指纹。
